# Skill: MCP проекта pulsenet

Сервер: `http://127.0.0.1:8010/mcp`, токен в `PULSENET_MCP_TOKEN`. Полное описание инструментов,
токенов и ошибок — в `docs/MCP.md` проекта. Правила работы с памятью — в `AGENTS.md`.

## Основной порядок

1. Перед задачей: `triplex_search` с формулировкой задачи. Используйте найденные факты и скажите об этом.
2. Если память расходится с реальностью: `triplex_supersede` или `triplex_retract`.
3. После подтверждённого решения: `triplex_ingest` → `doc_id` → `triplex_assert` с `doc_id` и `span`.
4. Не записывайте секреты и догадки.

Память общая для ваших агентов (`MCP_MEMORY_SCOPE=shared`). Автор каждого факта определяется токеном
и виден в `triplex_facts` в поле `agent`. Передавать его не нужно.

## Если сомневаетесь в названиях

Вызовите `pulsenet_guide` (описание сервера и состояние памяти) и `whoami`. Не угадывайте имена
инструментов и аргументы: список берите из `tools/list`.

## Изображения

`image_generate(prompt, seed, steps, width, height, negative_prompt, backends, return_image)`.
Промпт формулирует агент сам. Для быстрой проверки цепочки бэкендов: `image_generate` с
`steps: 6` и `return_image: false`.
