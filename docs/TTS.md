# Озвучка ответов

Озвучка работает локально. Движок выбирается переменной `TTS_ENGINE` в `.env`.
**По умолчанию стоит `silero`** — самый лёгкий вариант из уже установленных: модель 38 МБ лежит в
`data_unified/tts/`, скачивать ничего не нужно. XTTS оставлен как альтернатива и включается одной
строкой (но веса ~2 ГБ и первая фраза ~35 с).

| Движок | Языки | Нужно установить | Голоса |
|---|---|---|---|
| `silero` (используется) | русский | torch (уже стоит, CPU) | 5 встроенных голосов |
| `piper` (ещё легче) | русский, английский и любые другие, для которых есть голос Piper | `piper-tts` (без torch и FFmpeg) | файлы `.onnx`, все перечисленные в `PIPER_VOICES` |
| `xtts` (тяжёлый) | 17 языков, включая русский | torch, `coqui-tts`, `six` | 58 встроенных голосов модели или образец `XTTS_SPEAKER_WAV` |

Все три движка работают на CPU. На этой машине torch уже стоит CPU-сборкой (`2.15.0+cpu`), CUDA не нужна.
Меню выбора голоса показывает голоса текущего движка сразу, до загрузки модели. При смене движка
устаревшие id (`xenia` после XTTS, `ru-irina` после Piper и т.п.) сервер и интерфейс отбрасывают —
вместо них берётся голос по умолчанию из `.env`.

Если озвучка не работает, интерфейс переходит на голос браузера. Чат от этого не страдает.

## Piper (самый лёгкий, но нужны файлы голосов)

**1. Установить пакет.** Одна команда, torch и FFmpeg не нужны:

    .venv\Scripts\python.exe -m pip install -r requirements-tts.txt

**2. Скачать голоса.** Голоса лежат в репозитории `rhasspy/piper-voices` на huggingface.co. Для каждого голоса нужны два файла в одной папке: `.onnx` и `.onnx.json`.
Рекомендуемые варианты:
- русский: `ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx`;
- английский: `en/en_US/lessac/medium/en_US-lessac-medium.onnx`.

Если путь в репозитории изменился, найдите голос по имени (`ru_RU-irina`) на странице репозитория. Положите файлы, например, в `C:\piper-voices\`.

**3. Указать в `.env`:**

    TTS_ENGINE=piper
    TTS_ENABLED=1
    PIPER_VOICES=ru-irina=C:\piper-voices\ru_RU-irina-medium.onnx;en-lessac=C:\piper-voices\en_US-lessac-medium.onnx

Несколько голосов задаются в одной строке через «;». Формат каждого элемента: `id=путь`. id обязан начинаться с языка: `ru-` или `en-`. Например, чтобы добавить второй русский голос:

    PIPER_VOICES=ru-irina=C:\piper-voices\ru_RU-irina-medium.onnx;ru-dmitri=C:\piper-voices\ru_RU-dmitri-medium.onnx;en-lessac=C:\piper-voices\en_US-lessac-medium.onnx

Все голоса появятся в списке выбора голоса в интерфейсе. Первый голос каждого языка используется по умолчанию для этого языка.
Английский голос необязателен: без него английский текст читается русским голосом.

**4. Перезапустить сервер** (`run_server.bat stop`, затем `run_server.bat`) и проверить `http://127.0.0.1:8000/api/tts/status`: `available` должно быть `true`, а `missing_voice_files` — пустым.

**Как выбирается голос.** Если выбран голос в интерфейсе, озвучка идёт им. Иначе язык определяется по тексту: если латиницы заметно больше кириллицы, берётся первый английский голос, иначе первый русский.

## Silero (по умолчанию, только русский)

Нужен torch: `.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu`.
В `.env`: `TTS_ENGINE=silero`, `SILERO_ENABLED=1`. Модель `v4_ru.pt` скачивается с models.silero.ai в `data_unified\tts\`
либо включается `SILERO_AUTODOWNLOAD=1`. Синтез вызывается с расстановкой ударений и восстановлением «ё».

## XTTS-v2 (тяжёлый, 17 языков)

**1. Зависимости.** torch уже установлен в `.venv` (CPU-сборка подходит). Дополнительные пакеты:

    .venv\Scripts\python.exe -m pip install -r requirements-tts-xtts.txt

`requirements-tts-xtts.txt` ставит `coqui-tts`, `six` и `transformers>=4.57,<5`. Без `six` импорт
`TTS.api` падает с `ModuleNotFoundError: No module named 'six'`. На `transformers 5.x` модель
загружается, но синтез падает с `'NoneType' object has no attribute 'get_seq_length'`: в 5.x генерация
передаёт `cache`, а XTTS из coqui ожидает `past_key_values`. Проверено на 4.57.6 — работает.
Модель загружается лениво и **один раз на процесс**: первый синтез даёт ~38 с (загрузка + речь),
следующие — ~6 с на короткую фразу, новый экземпляр `TTS` не создаётся.

**2. `.env`:**

    TTS_ENGINE=xtts
    TTS_ENABLED=1
    XTTS_ACCEPT_LICENSE=1
    XTTS_LANGUAGE=ru
    XTTS_DEVICE=cpu
    XTTS_SPEAKER=Claribel Dervla

Модель XTTS-v2 распространяется по лицензии CPML (только некоммерческое использование), поэтому
загрузка разрешается только явным `XTTS_ACCEPT_LICENSE=1`. Веса (несколько ГБ) скачиваются при
первом запросе. Список из 58 встроенных голосов зашит в `pulsenet/tts_xtts.py` (взято из
`speakers_xtts.pth` модели), поэтому меню работает до загрузки весов. Голос по умолчанию задаётся
`XTTS_SPEAKER`, конкретный голос можно выбрать в интерфейсе — он передаётся только в этом запросе.
Вместо имени можно дать `XTTS_SPEAKER_WAV` — тогда модель скопирует тембр из образца (меню покажет
один пункт «Образец голоса»).

## Общее

- Перед озвучкой текст очищается: код, таблицы, ссылки и разметка не читаются вслух. `%`, `₽`, `&`, `№` читаются словами.
- Ответ делится на фразы; озвучка идёт по фразам.
- Проверка состояния: `GET /api/tts/status`, поля `engine`, `ready`, `available`, `error`, `voices`, `missing_voice_files`.
- Качество звука на вашей машине в песочнице не проверялось.
